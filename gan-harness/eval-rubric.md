# Design evaluation rubric

Score each criterion from 0 to 10. Multiply by its weight. The weighted total must reach 7.5 to pass.

## Design Quality, weight 0.35
- 9 to 10. Hierarchy is obvious at a glance. One primary reading, everything else supports it. Spacing and type scale feel deliberate at 360 px and at 1440 px.
- 7 to 8. Clear hierarchy with one weak zone.
- 5 to 6. Several elements compete. The eye needs a second pass.
- 0 to 4. Flat grid of equal cards with no reading order.

## Originality, weight 0.30
- 9 to 10. A device-specific idea that would not transfer unchanged to another dashboard. Motion or structure carries meaning.
- 7 to 8. One distinctive element, rest is conventional but well resolved.
- 5 to 6. Competent dark dashboard, interchangeable with any sensor project.
- 0 to 4. Template look.

## Craft, weight 0.25
- Typography, tabular numerals, alignment, contrast, state transitions, disconnected state, touch targets of at least 44 px, no layout shift when values change width.
- Deduct for clipped text, misaligned decimals, hover-only affordances, or values that jump between one and two digits.

## Functionality, weight 0.10
- All required values visible, mode control works against the real endpoint shape, reset asks for confirmation, polling survives a failed request, no external requests.

## Evaluator question
Would this win a design award, or would it pass a code review. Score for the first.
